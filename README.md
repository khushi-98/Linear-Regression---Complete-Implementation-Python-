# 📘 Linear Regression - Complete Implementation (Python)

This project demonstrates a **complete implementation of Linear Regression** using Python and Scikit-learn.

---

## 🚀 Project Overview

Linear Regression is a **supervised machine learning algorithm** used to predict **continuous values** by fitting a straight line (or hyperplane) to the data.

This project covers:
- ✅ Simple Linear Regression  
- ✅ Multiple Linear Regression  
- ✅ Model Evaluation (MSE & R² Score)  
- ✅ Predictions on new data  
- ✅ Residual Analysis  

---

## 🛠️ Tech Stack

- Python 🐍  
- NumPy  
- Pandas  
- Matplotlib  
- Scikit-learn  

---

linear-regression/

## 🔹 Simple Linear Regression

- Uses **one feature**
- Example: `Hours Studied → Score`

### Steps:
- Generate dataset  
- Train model  
- Predict values  
- Evaluate using:
  - Mean Squared Error (MSE)
  - R² Score  

---

## 🔹 Multiple Linear Regression

- Uses **multiple features**
- Example:
  - Hours  
  - Practice  
  - Sleep  

### Steps:
- Create dataset  
- Train model  
- Evaluate performance  
- Predict new values  

---

## 🔹 Residual Analysis

Residuals = **Actual - Predicted**

- Helps evaluate model performance  
- Ideal case: random distribution around 0  

---

## 📊 Evaluation Metrics

| Metric | Description |
|--------|------------|
| MSE    | Average squared error |
| R²     | Model accuracy (closer to 1 is better) |
